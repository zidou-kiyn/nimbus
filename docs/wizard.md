# 🌱 新机开荒

把一台新服务器从「刚开机」到「可以放心用」的初始化步骤，按推荐顺序集中在一个菜单里。

```bash
nb init        # 或：nb → 9
```

每次进入都会**实时检测**各步骤的状态，所以中途退出、重启后回来继续都没关系。

## 状态图标

| 图标 | 含义 |
|:---:|---|
| ✔ | 已完成（检测到已配置，或已手动标记完成） |
| ○ | 待处理 |
| ⚠ | 需注意，例如装了新内核但还没重启 |
| – | 已跳过，或当前系统不适用 |

标注「可选」的步骤不参与推荐，按需执行。

## 步骤

| 阶段 | # | 步骤 | 说明 |
|---|:---:|---|---|
| 一 · 系统安装 | 1 | 重装系统（可选） | InstallNET，可自定义版本 / 密码 / 端口 / RAID，见 [功能详解](features.md#重装系统) |
| 二 · 基础与内核 | 2 | 修改 root 密码 | 重装用的是临时密码时，请第一时间修改 |
| | 3 | 更新系统软件包 | 先更新，再换内核，只需重启一次 |
| | 4 | 内核与 BBR 加速 | XanMod + BBRv3；PVE / 容器 / ARM 只开 BBR + fq |
| | 5 | 重启并检查内核 | 检测是否有待启用的新内核 |
| 三 · 系统设置 | 6 | 系统时区 | |
| | 7 | 主机名 | 同步更新 `/etc/hosts`；PVE 宿主机会先警告 |
| | 8 | 本机 hosts 解析 | 确保主机名可解析，避免 sudo 变慢 |
| | 9 | 虚拟内存 | |
| | 10 | 优化 DNS | |
| | 11 | 自动安装安全更新 | 仅 Debian / Ubuntu，其他系统显示「不适用」 |
| 四 · SSH 与账号安全 | 12 | SSH 密钥登录 | 导入公钥后禁用密码登录 |
| | 13 | 修改 SSH 端口 | 同步 fail2ban 的端口 |
| | 14 | 新建 sudo 用户并禁用 root（可选） | |
| | 15 | fail2ban SSH 防御 | |
| 五 · 环境与监控 | 16 | tmux 及推荐配置 | |
| | 17 | TG-bot 监控预警（可选） | 资源告警 + SSH 登录提醒 |
| | 18 | 切换系统语言 | |
| | 19 | 命令行美化 | |
| 六 · 应用部署 | 20 | Komari 探针（可选） | |
| | 21 | Realm 端口转发（可选） | xwPF |
| | 22 | XBoard-node 节点（可选） | |

> [!TIP]
> 修改 SSH 端口、禁用密码登录之后，**先保持当前会话**，另开一个终端确认能用新方式登录，再关闭旧会话。

## 操作

| 输入 | 作用 |
|---|---|
| `编号` | 执行该步骤 |
| `n` | 执行推荐的下一步 |
| `s` | 跳过推荐的这一步（不想做时用） |
| `m 编号…` | 切换完成 / 未完成，例如 `m 3 6 9` |
| `a 编号…` | 清除手动标记，恢复自动检测 |
| `r` | 清除全部执行记录和手动标记 |
| `0` | 返回主菜单 |

- 已经做过但**检测不出来**的步骤（比如手动配置过），用 `m` 标记为完成。
- 检测显示已完成、但你想**重做**的，再用 `m` 切回未完成，它会重新进入推荐。
- 重新执行某一步后，该步的手动标记会自动清除，回到自动检测。

执行记录与手动标记保存在 `/etc/nimbus/wizard.state`。
